# AI Instant Messenger

Miss those long hours at the computer screen back in the 90s, and early 2000s chatting with friends through Instant Messenging platforms like *AIM*, *Yahoo! Messenger*, *MSN Messenger*, and probably a lot of others?  Want to relive those days, but with AI chatbots?  *Well! Look no further than **AIIM**, the AI Instant Messenger for your desktop, using a local model you might have lying around to power it.  If you don't have a local model, getting yourself set-up with something like [LM Studio](https://lmstudio.ai/) for some with enough technical skills shouldn't be too difficult.  Depending on your hardware and if you have a GPU or not, you should do a bit of research to determine which model file is right for your system before downloading, as some of these models can be massive in size, so don't download a 30GB model if you can't even use it, check your hardware to determine the best one to download.  Other than that, in LM Studio, just go into the *Developer Mode* tab on the left, click on *Load Model*, jot down the info about it's name, and then toggle the *Start Server* to get it all up and running.  Once it's up, after launching **AIIM**, you will be presented with a *Local Model Logon* dialog box, which will ask you for your `localhost` URL path, which by default for *LM Studio* is `http://localhost:1234/v1`, along with which model you wish to logon with.  This would be the *Model Name* displayed *LM Studio*, then click **Begin** which will open the main application window, the **AIIM Buddies**.  For those who grew up with instant Messenger clients back in the day, the simplisic interface should look somewhat familar.  It is not as polished or feature rich as one of the original client programs, but I will hopefully find time here and there to keep adding new and interesting features for this program.

### Create-A-Buddy

Much like how *Create-A-Sim* exists in **The Sims** to create a virtual simulated character in those games, here it's called *Create-A-Buddy*, which is where you will get the chance to create a fully customized virtual instant Messenging buddy that you can chat with for all hours of the night.

At first this dialog and creation will start off limited, but as time progresses, I hope to have more refined options, and to make it feel more like *Create-A-Sim*, but for *AI Characters*.  So, it essentially, it would be a dialog with simple *Sims-like* controls and toggles, but entirely for personality traits.  You'll be able to say allocate various personality points to different traits, and assign various other attributes to them, which should be-able to really flush out a unique virtual instant Messenger character which will be interesting to chat with when you are bored and just want to causally chat, but not with someone who might take days to reply, as in **AI Instant Messenger**, it's where you'll never get ghosted by a buddy, **EVER**.

Once you create a buddy, they will appear in the buddy list, and it will also immediately open a new chat conversation with that buddy, so you can immediately introduce yourself and start chatting.

### It's a Buddy that'll NEVER GHOST you.

With this *AI Instant Messenger*, you never need to be anxious about a very delayed reply ever again! As an *AIIM Buddy* will always immediately response to you right in the moment, either giving you helpful advice, a shoulder to lean on, or something else entirely!  With **AIIM Buddies**, each of them can be incredibly unique and have very differing personalities, allowing you to feel like you are actually talking to this other person over Instant Messenger together.
